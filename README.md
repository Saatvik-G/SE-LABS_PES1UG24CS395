# Software Engineering Lab Coursework

This repository contains the deliverables for the Software Engineering Lab course.

For each laboratory session, a separate directory is created containing the respective UML models, requirements tables, specifications, and related artifacts.

## Navigation
*   **[Lab 1: Requirements Engineering & UML Use-Case Modelling](./Lab_1/)**
    *   **Problem Statement:** Warehouse Inventory & Pallet Location Tracker
    *   **Deliverables:** Requirements Specification (PDF/DOCX), Stick-Figure UML Use-Case Diagram (PDF), and Use-Case Flow Document (PDF/DOCX).
*   **[Lab 2: Agile Backlog Creation & Sprint Simulation in Jira](./Lab_2/)**
    *   **Problem Statement:** Warehouse Inventory & Pallet Location Tracker
    *   **Deliverables:** Product Backlog (Epics & Stories), Active Sprint Board Mockup, Burndown Chart, and Reflections.
